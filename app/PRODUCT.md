# Product Context

## Product
Portfolio website for software developer

## Users
Recruiters, potential clients, remote job seekers

## Where They Use It
Viewing on desktop or mobile during job search, portfolio review sessions

## What They Do
1. Land on home page
2. Read profile and skills
3. Review portfolio projects
4. Download CV or contact
5. Return to check for updates

## Brand Voice
Professional, modern, no hyperbole. "Here's what I can do" not "I can boost your productivity"

## Anti-References
- ❌ Purple gradients
- ❌ Glassmorphism or frosted glass effects
- ❌ Generic "Welcome to our platform" messaging
- ❌ Bouncy or springy animations
- ❌ Vague button text
- ❌ AI-generated stock photography

## Success Metrics
- Portfolio loads in < 2 seconds
- All interactive elements are clearly clickable
- Mobile navigation is easy to use
- Theme toggle works smoothly
- Color contrast passes WCAG AA

## Non-Goals
- Real-time notifications
- User accounts/login
- Comments or feedback system
- Backend API (static site only)

## Constraints
- Single static site (no server needed)
- Offline browsing should work
- Must support dark and light themes
- No external dependencies for core functionality
- Build must complete in < 5 seconds
