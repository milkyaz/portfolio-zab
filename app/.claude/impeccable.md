# Impeccable Design Skill

## Available Commands

- `/impeccable shape` - Create a design brief from discovery questions
- `/impeccable craft` - Full shape-then-build flow for brand-new features
- `/impeccable polish` - Polish existing UI and fix design issues
- `/impeccable typeset` - Apply typography system
- `/impeccable colorize` - Apply color palette and ensure WCAG contrast
- `/impeccable animate` - Add meaningful motion with physics-based easing
- `/impeccable detect` - Check for design anti-patterns (41 rules)

## Design System Context

- **Framework**: Vue.js 3 with TypeScript
- **Styling**: Tailwind CSS v4 + DaisyUI v5
- **Color Mode**: Dark theme by default with light theme toggle
- **Typography**: Poppins font family
- **Spacing**: Tailwind default scale with custom 7.5px gaps

## Component Library

- ProfileButton: Primary (yellow #FFE071) and Ghost styles
- ProfileInfo: Hero section with profile details
- ProfileFactList: Fact cards display
- TabSwitch: Tabbed interface for Portfolio and Skills
- ButtonTheme: Dark/light theme toggle

## Design Tokens

- Primary: #FFE071 (yellow)
- Dark bg: #0C151D, #0B1218
- Text: #3D3D3D, #A3ABB2
- Border: #171F26

## Before Designing

Check:
1. PRODUCT.md or project README for brand voice and constraints
2. Existing component structure in src/components/
3. Current Tailwind color scheme and spacing
4. Theme support - dark/light mode required
