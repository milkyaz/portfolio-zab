# Impeccable for GitHub Copilot

This project uses Impeccable to maintain design quality and prevent AI-generated UI "slop".

## Quick Commands

When working on new features, use these Impeccable workflows:

### For New Features
1. **Design First**: Describe what users need
2. **Use `/impeccable shape`**: Create a design brief
3. **Use `/impeccable craft`**: Build the component with design system

### For Existing UI
- **`/impeccable polish`**: Fix styling issues
- **`/impeccable typeset`**: Fix typography
- **`/impeccable colorize`**: Fix colors and contrast
- **`/impeccable animate`**: Add motion

### Quality Checks
- **`/impeccable detect`**: Run linter for design anti-patterns

## Design System Rules

### DO:
- Use consistent spacing (7.5px base unit)
- Apply theme-aware colors (use DaisyUI classes)
- Include clear focus states for interactivity
- Animate with physics-based easing
- Make content responsive mobile-first

### DON'T:
- Add purple gradients
- Use glassmorphism effects
- Include placeholder copy like "Welcome to our platform"
- Default to Modal dialogs
- Overuse box shadows

## Theme Support

All new components must support both light and dark themes:
```vue
<div class="bg-base-100 text-base-content">
  <!-- Uses DaisyUI theme variables -->
</div>
```
